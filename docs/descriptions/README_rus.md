# C++ Messenger

Русская версия описания временно сведена к краткой заметке, чтобы не дублировать устаревшие обещания.

Актуальная документация находится в [основном README](../../README.md).

Коротко: проект является экспериментальным C++17/Qt/PostgreSQL прототипом мессенджера, а не production-ready продуктом. В текущей версии исправлены важные проблемы прототипа: убраны захардкоженные секреты, добавлены миграции БД, `password_hash`, framed TCP protocol, пул соединений PostgreSQL и базовые тесты. TLS пока не реализован.
