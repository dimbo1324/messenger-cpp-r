# C++ Messenger

La documentacion principal actualizada esta en [README.md](../../README.md).

Resumen: este proyecto es un prototipo experimental de messenger en C++17/Qt/PostgreSQL, no un producto production-ready. La version actual elimina secretos hardcodeados, agrega migraciones de base de datos, `password_hash`, protocolo TCP con frames, pool de conexiones PostgreSQL y pruebas basicas. TLS todavia no esta implementado.
